# 利润宝 Web 前端外壳 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付可由 macOS `.command` 启动、可在本机浏览器预览的 React 前端外壳，为后续逐项接入现有 `core/` 功能建立稳定边界。

**Architecture:** FastAPI 仅监听 `127.0.0.1` 并提供健康检查与前端静态文件；React + Vite 实现七个工作区页面、模拟状态和视觉系统。前端只使用模拟数据，现有 Tk 和 `core/` 不修改，后续迁移通过 API 逐项替换模拟数据。

**Tech Stack:** Python 3.11+、FastAPI、Uvicorn、React、Vite、TypeScript、CSS、pytest。

## Global Constraints

- 后端只能绑定 `127.0.0.1`，不得提供局域网或公网访问。
- 不得修改 `core/` 的计算、诊断、互动、预算或导出规则；Tk 入口保持可用。
- 新增依赖须登记 `requirements.txt`，并同步更新 `.hooks/project_guardian.py` 的模块清单和 ADR 检查。
- 所有建议与 UI 文案保持合法税务筹划边界；增值税税负率必须标注“估算值（基于税金及附加反推）”。
- 所有 Web 新文件采用项目智能体标识与日期时间命名；标准运行时清单文件采用生态约定名称并在本阶段文档中显式记录。
- 完成前必须验证 API 绑定地址、前端构建、前端页面、原 Tk 演示和既有 `core/` 测试。
