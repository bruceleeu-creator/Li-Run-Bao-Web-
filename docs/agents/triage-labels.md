# Triage Labels

技能使用五个规范分诊角色。本文件把这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库的标签 | 含义 |
| -------------------------- | ------------ | ---------------------------------------- |
| `needs-triage`             | `needs-triage` | 维护者需要评估该 issue |
| `needs-info`               | `needs-info`   | 等待报告方补充信息 |
| `ready-for-agent`          | `ready-for-agent` | 规格完整，可供 AFK agent 处理 |
| `ready-for-human`          | `ready-for-human` | 需要人工实现 |
| `wontfix`                  | `wontfix`      | 不处理 |

当技能提到某个角色（例如 "apply the AFK-ready triage label"）时，使用上表中对应的标签字符串。

如需匹配你实际使用的词汇，可直接编辑右列。
