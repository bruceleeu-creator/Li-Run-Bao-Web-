# AI 完整财报合并报告修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完整读取云南艺康三份审计报告的全部 122 页，使用 DeepSeek V4 Flash 分段提取并校验，生成不截断、企业和年份正确的 2022—2024 跨年分析报告。

**Architecture:** 将浏览器预览与后台完整读取彻底分离。导入会话保存源文件快照；后台任务逐页提取并缓存完整文本，按文件分段调用 AI，使用确定性指标校验后再合并报告，只有身份、页数、年份和停止原因全部通过校验才保存。

**Tech Stack:** Python 3.13、FastAPI、SQLite、pypdfium2、pdfplumber、RapidOCR、requests、React 18、TypeScript、Vite、pytest、Playwright。

class PDFPageRecord:
