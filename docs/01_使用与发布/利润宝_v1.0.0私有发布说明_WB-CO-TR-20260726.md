## 一、本次发布概述

利润宝 v1.0.0 是首个**可交付给财税/代账机构同事使用**的本地应用版本，基于 CO（CODEX）T8 最终独立验收通过的代码基线构建，配套 T10 保守清理与 macOS 封装。

### 核心闭环

```
[数据导入] 三年财报 + 科目余额表（Excel/CSV）
    ↓
[第一轮·AI诊断] 行业对标 → 税负率诊断 + 成本费用结构分析
    ↓
[多轮互动] 每轮 3 个选项 → 用户选/补充
    ↓
[第二稿] 环比同比、增值比例与幅度、操作细节
    ↓ 双方确认 或 落地性 >95%
[完整方案] Word/PDF 报告 + Excel 成本优化测算模型
```

## 二、本次发布包含的功能

### F1-F9 核心闭环

- **数据导入**：Excel/CSV 三表（利润表 / 资产负债表 / 科目余额表），同义词词典自动归并金蝶/用友项目名差异。
- **行业对标诊断**：税负率（增值税基于税金及附加反推·估算值，已显著标注）、所得税税负率、综合税负率、毛利率、各项费用率。
- **多轮 AI 互动**：每轮针对一条发现给出 A/B/C 三个选项（含影响测算与落地可行性），用户可补充战略意图。
- **第二稿**：含历史环比同比、增值比例与幅度、操作细节与注意事项。
- **完整方案导出**：Word/PDF 报告（7 章节）+ Excel 成本优化测算模型（三 Sheet：费用预算表 / 行业参考 / 诊断与行动清单）。

### 模板版预算引擎（T6.1-T6.6）

- 84 行企业成本费用计划表模板导入与导出。
- 同一工作簿三 Sheet 强制（费用预算表 + 行业企业所得税贡献率参考 + 诊断与行动清单）。
- A/B/C 列优先读取用户文件维护内容。
- 原模板防覆盖：比较 `os.path.realpath` 后同路径直接抛 `TemplateError`。
- `read_template` 校验 Sheet 名 + 关键标签 A1/A12/A13/D13/G13/I13 + 84 行结构。

### T7 P0/P1 整改

- **P0-1**：真实可见 Tk 窗口布局（grid + 滚动条 + 三个导出按钮 w/h > 1）。
- **P0-2**：`write_template` 同工作簿三 Sheet。
- **P0-3**：核心层比较规范化路径，禁止覆盖原始模板。
- **P0-4**：Word/PDF 7 章节 + 11 列诊断建议分栏。
- **P1-1**：`validate_plan` 拒绝负金额 / 越界比例 / 非法税率。
- **P1-2**：Excel E4 数据验证下拉 + J 列条件格式 + 打印设置。
- **P1-3**：`read_template` 结构校验 + A/B/C 列读取。
- **P1-4**：旧 `.ai_config.json` 含 `api_key` 时原子重写为仅 `base_url/model`。

### T10 macOS 封装

- 5 个 `.command` / `.sh` 双击脚本（安装/启动/环境检查/质量检查/构建发布包）。
- 全部从脚本自身位置解析项目根目录，不写死用户名/绝对路径。
- 自动查找 Python（`LRB_PYTHON` → `python3.13` → `python3.12` → `python3.11` → `python3`）。
- 安装失败给出清晰中文提示，不静默失败，不自动安装 Homebrew。

## 五、合规与安全声明

- **客户财务数据只在本机处理**，未经用户明确授权不会触网。
- AI 引擎为**可选增强**，未配置时由规则引擎兜底，离线可跑通完整闭环。
- 所有优化建议限于**合法税务筹划**范畴（研发加计扣除、限额内据实扣除、业务模式优化等）；严禁违规筹划。
- 增值税税负率为**估算值**（基于税金及附加反推），UI/报告/Excel 三处均显著标注。
- 真实 API Key/Token/密码不会进入仓库；`.ai_config.json` 已在 `.gitignore` 中忽略。
- 发布包已扫描本机路径、微信路径、用户名等敏感字符串，命中即中止构建。

## 六、已知限制

- 增值税税负率为估算值（由税金及附加反推），如能直连开票/申报系统可取真实应纳税额。
- 行业基准为经验区间，可按机构自身客户样本持续校准。
- v1.0 不支持 OCR、多客户组合管理、直连金蝶/用友 API（v2.0 规划）。
