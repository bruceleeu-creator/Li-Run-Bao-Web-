# 利润宝 · 企业财税优化顾问（Web 版）

面向**财税/代账机构**的本地化智能分析工具：导入企业近三年财报，自动完成行业对标诊断与数字质检，通过多轮 AI 互动收敛出可落地的优化方案，一键产出 Word/PDF 报告与可运行的 Excel 成本优化测算模型。

> **核心理念**：所有财税计算均为确定性数学，可逐笔由原始报表反算复核；AI 仅作可选增强，未配置时由内置规则引擎兜底——**离线也能跑通完整闭环**。客户财务数据只在本机处理，绝不外传。

## 一、产品定位与价值

### 解决什么问题

财税/代账机构在服务客户时普遍面临四个痛点：

| 痛点 | 利润宝的解法 |
|------|--------------|
| 手工分析依赖顾问个人经验，耗时长、口径不统一 | 导入即自动诊断，单客户从导入到出方案 ≤5 分钟，口径全部标准化 |
| 税负率/成本结构与行业对标缺乏系统化工具，容易遗漏 | 内置 22 个行业参考区间与判定规则，自动识别「该有没的」「可有可没有」「真实性风险」 |
| 优化建议是一次性结论，缺乏与客户战略意图的互动 | 每条发现给出 A/B/C 三个可量化选项，客户选路径、提意图，方案迭代收敛 |
| 数字提取错误难以发现，报告可信度受影响 | 独立的**数字质检引擎**双层防护（原文 OCR 字面 + 会计恒等式交叉验证），高风险数字必须人工核验后才能导出 |

### 交付物

- **Word/PDF 优化报告**：经营目标、预算汇总、超支异常明细、84 行明细、诊断与优化建议、完整计算口径、合规声明七章结构
- **Excel 成本优化测算模型**：方案概览、行动测算（当前值→目标值→变动幅度→预计节税）、可逐月勾选跟踪的执行清单
- **费用预算三表**：费用预算表 / 行业企业所得税贡献率参考 / 诊断与行动清单

## 二、核心闭环

```
[数据导入] 拖入/选择 Excel·CSV·Word·PPT·PDF（多年审计报告自动合并）
    ↓ 自动：企业识别 + 行业推荐 + 数字质检 + 数据质量评估
[数字质检] 恒等式核对 · 小数点错位归因 · OCR 原文字面检查
    ↓
[第一轮诊断] 行业对标 → 税负率诊断 + 成本费用结构分析（初稿建议）
    ↓
[多轮互动] 每条发现给 A/B/C 三个选项（各带影响测算与落地可行性）
    ↓        可输入战略意图（如"往研发型企业转型"）
[第二稿] 环比同比 + 增值比例与幅度 + 操作细节 + 注意事项
    ↓ 双方确认 或 落地性 ≥95%
[完整方案] → 导出 Word/PDF 报告 + Excel 测算模型
```

全程产生的**导入记录卡片**与**报告记录**保存在本机，点击即可完整载入该案例（含诊断与互动进度），随时继续未完成的分析。

## 三、功能与原理详解

### 3.1 财报导入（多格式 · 双通道解析）

- **支持格式**：`.xlsx` `.csv` `.docx` `.pptx` `.pdf`
- **两种数据形态**：
  - 单文件含三 Sheet（利润表/资产负债表/科目余额表）→ 直接解析
  - 多文件（每年一份完整审计报告）→ 按 科目+年份 自动合并成多年数据集
- **双通道解析**：
  - 文本层直读（Excel 表格 / PDF 文本层 / Word·PPT 表格）
  - 扫描件（无文本层的 PDF）→ 逐页 OCR → 整份送 DeepSeek 结构化解析 → 映射为标准数据模型（需配置 AI）
- **同义词归并**：金蝶/用友等不同财务软件的科目命名差异，通过内置同义词词典自动归一到规范科目（约 50 组映射）
- **自动识别**：选完文件自动识别企业名称与行业（AI 优先、规则回退），填入表单供确认；行业选择支持 AI 推荐

### 3.2 数字质检（独立分析层，双层防护）

因程序核心是文档数据的处理与分析，数字正确性由专门的 `core/numeric_audit.py` 引擎保障——**只提示、绝不静默改数**：

**第一层 · 扫描层（OCR 原文字面质检）**：扫描导入时采集的原文/OCR 文本，点名可疑数字字面——形近字母混入（O↔0、I/l↔1、S↔5、B↔8、Z↔2）、超长粘连数字、全角数字、千分位与小数点混用。

**第二层 · 数字层（交叉验证）**：
- **会计恒等式全式核对**：利润总额 ≈ 营收−成本−税金及附加−四费（残差≤2%营收视为正常杂项）；资产总额 = 负债+所有者权益（容差万分之一）
- **小数点错位归因**：若某科目 ×10/100/1000 后恒等式残差骤减至原 1/100，高置信判定错位并给出修正建议（如 `22,263,237,393 → 222,632,373.93`）
- **逐年跳变**（>80% 提示核对）、**业务合理性**（负营收、毛利率超区间、单项费用大于营收、利润与净利反号）

质检结果以**评分 + 等级 + 逐条发现**展示在导入页；**任一高风险发现将要求导出前人工核验关键金额**。

### 3.3 诊断引擎（行业对标）

- 基于近三年数据计算：增值税税负率（估算口径）、所得税税负率、综合税负率、毛利率、各项费用率、净利率
- 对标 22 个行业的参考区间（P25–P75 分位法 + 经验中枢法），识别：
  - **该有没的**：如研发费用缺失、福利/教育经费未用足限额
  - **可有可没有/应控**：如业务招待费超限、咨询费占比偏高
  - **真实性风险**：增值税税负率异常偏低等预警
- 可选 AI 增强：DeepSeek 补充发现与优化 A/B/C 出题（失败静默回退规则引擎）

### 3.4 A/B/C 互动与方案收敛

- 严格状态机驱动：`决策轮次 → 第二稿 → 确认 → 最终方案`，不跳项、可断点续作
- 每条发现三个选项（激进/平衡/保守），各带净影响、可行性、风险分级与分栏金额测算
- 落地性评分可解释（未决高风险项 + 暂维持选择 + 可行性加权）；**落地性 ≥95% 或用户确认**即解锁导出
- 互动进度自动快照——切换案例后再切回，从断点继续

### 3.5 案例管理（导入记录 + 报告记录）

- **每次导入自动生成记录卡片**（企业/年份/行业/文件数/时间），点击**完整载入**该案例：财务数据、诊断结果、互动进度、解锁状态、已生成的 AI 报告一并恢复，不重复整理
- **报告记录**：AI 整理与合并报告自动存档；点击报告 = 预览内容 + 载入其对应案例
- 全部记录存本机 SQLite（上限 50 条），重启不丢

### 3.6 AI 能力（可选增强，离线兜底）

配置 OpenAI 兼容接口（默认 DeepSeek）后启用：扫描件 PDF 解析、AI 整理（整理完成自动导入）、跨年合并报告（逐页分段提取 + 确定性校验，防截断）、指标识别、诊断增强。**未配置或调用失败时静默回退规则引擎，主流程永不阻塞**。API Key 持久化于本机 `.ai_config.json`（已 gitignore），仅内存持有。

## 四、技术架构

### 分层（强制单向依赖）

```
web_backend/（FastAPI，仅 127.0.0.1:8765）      HTTP 适配层
    ↓ 只调 Pipeline 门面
core/pipeline.py  run_case_pipeline              编排层
    ↓
parser(抽取) → reconciliation(归一/勾稽) → numeric_audit(数字质检)
    → PolicySnapshot(税率/费用帽单点) → CaseBundle
    ↓
FinancialData（唯一数据真源）
    ↓ 只读
diagnostic / interactive / budget / report / action_pack
```

### 核心模块

| 模块 | 职责 |
|------|------|
| `core/parser.py` | 五格式抽取（文本层/OCR/AI 三通道），年份对齐 |
| `core/numeric_audit.py` | 数字质检引擎（双层防护 + 评分 + 修正建议） |
| `core/reconciliation.py` | 科目归一、跨年勾稽（R1/R2/R3）、贡献率合成 |
| `core/pipeline.py` + `case_manifest.py` | 统一导入管线 + 案例包（新案例零代码接入） |
| `core/industry.py` | 22 行业基准库（7 字段区间 + 预警线） |
| `core/finance.py` | 税负率/结构/环比测算（确定性数学） |
| `core/diagnostic.py` / `interactive.py` | 诊断引擎 / 互动状态机 |
| `core/ai_engine.py` | 可选大模型接口（OpenAI 兼容，禁用 thinking 防截断） |
| `core/report.py` / `action_pack.py` / `budget_template.py` | Word/PDF 报告 / Excel 测算模型 / 84 行预算三表 |
| `web_backend/` + `web_frontend/` | FastAPI 后端（SQLite 持久化）+ React/Vite 前端 |

完整开发护栏（契约、坑点、验收命令）见 **[AGENTS.md](AGENTS.md)**（项目唯一文档真源）。

## 五、部署指南

### 5.1 环境要求

| 项 | 要求 |
|----|------|
| 操作系统 | macOS 12+ |
| Python | 3.11 或 3.12（**不要用 3.13**：OCR 依赖 rapidocr_onnxruntime 不支持） |
| Node.js | 20+（仅首次构建前端需要） |
| 磁盘 | ≥200MB |
| 网络 | 仅安装时需要；运行离线优先，AI 未配置时不触网 |

### 5.2 方式 A：双击脚本（推荐给财税/代账同事）

1. 进入 `scripts/` 目录，**双击** `安装利润宝_WB-CO-TR-20260726.command`——自动查找 Python 3.11+、创建 `.venv/`、安装依赖并自检
   - 若 Gatekeeper 拦截：右键脚本 →「打开」→「仍要打开」
2. **双击** `启动利润宝Web_WB-CO-TR-20260805160732.command`——自动启动本机服务并打开浏览器 `http://127.0.0.1:8765`
3. （可选）`环境检查` / `质量检查` 两个脚本用于自检与全量回归

### 5.3 方式 B：终端命令（开发者）

```bash
cd 利润宝
python3.11 -m venv .venv                 # 或 python3.12
source .venv/bin/activate
pip install -r requirements.txt

# 构建前端（仅首次或前端有更新时）
cd web_frontend && npm install && npm run build && cd ..

# 启动服务（仅绑定本机回环地址）
.venv/bin/python -m web_backend.CO_run_WB-CO-TR-20260805160732
```

浏览器访问 `http://127.0.0.1:8765` 即可。

### 5.4 可选：配置 AI

「设置」页填入 Base URL / 模型 / API Key（三字段齐全才可保存），保存后全局生效、重启免重输。默认适配 DeepSeek（`https://api.deepseek.com` + `deepseek-v4-flash`），任何 OpenAI 兼容接口均可。不配置则全程规则引擎离线运行。

### 5.5 数据模板（Excel 三 Sheet）

| Sheet | 结构 |
|-------|------|
| `利润表` | 首列=项目，其余列=各年金额（表头如 `2021`/`2022`/`2023`） |
| `资产负债表` | 同上 |
| `科目余额表` | 列含 `科目名称`、`期末余额` |

不同财务软件的项目命名差异会自动归并；也可直接拖入多年审计报告 PDF。

### 5.6 常见问题

| 现象 | 处理 |
|------|------|
| 找不到 Python 3.11+ | `brew install python@3.12`，或 `export LRB_PYTHON=/路径/python3.12` 后重跑安装脚本 |
| 前端页面空白/旧版 | `cd web_frontend && npm install && npm run build` 后重启 |
| 扫描件 PDF 提示"请配置 AI" | 设置页配置 AI 后重试（扫描件需 AI 解析） |
| 数字质检出现高风险 | 按面板建议对照审计报告原文核对；确认无误后勾选"已人工核验"即可导出 |
| 真实模板验收 | `export LRB_REAL_TEMPLATE_PATH=... ` 后运行 `tests/test_t7_acceptance.py` |

## 六、数据安全与合规

- **数据不出本机**：后端仅绑定 `127.0.0.1`；不收集统计、不回传信息；AI 为可选且密钥仅存本机
- **私有仓库分发**：不开源，仅授权内部财税/代账同事使用，不得二次分发
- **合法筹划边界**：所有优化建议限于合法税务筹划范畴（研发费用加计扣除、限额内据实扣除、业务模式优化等），严禁任何违规筹划表述；增值税税负率为估算口径（基于税金及附加反推），UI/报告/Excel 均显著标注；具体执行前建议与主管税务机关或注册税务师确认
- **数字不静默修改**：质检只提示与建议，任何修正必须人工对照原文确认

## 八、已知限制与路线图

**已知限制**
- 增值税税负率为估算值（由税金及附加反推）；接入开票/申报系统后可取真实应纳税额
- 行业基准为经验区间，可按机构自身客户样本持续校准
- 历史遗留测试失败：真实艺康 PDF 夹具缺失相关的 9 项（需原机器"测试文件"目录）；行业回退保留原名与发现项顺序两处行为与测试预期不符（已记录待修）

**路线图**
- v1.1：行业基准校准工具、报告模板自定义
- v2.0：多客户组合管理、直连金蝶/用友 API 取数、大模型深度润色
