# 利润宝 · 企业财税优化顾问（Web 版）

面向**财税/代账机构**的本地 Web 应用：导入企业近三年财报与科目余额表 → 按行业对标做税负率与成本费用结构诊断 → **多轮 AI 互动**（每轮给 3 个选项）→ 生成第二稿（含环比同比、增值比例与幅度、操作细节）→ 双方确认或落地性 >95% 时输出**完整方案**，并可一键导出 Word/PDF 报告与可运行的 **成本优化测算模型**。

> 全部计算为确定性数学，可逐笔由原始报表反算复核；AI 交互的大模型为**可选项**，未配置时由内置规则引擎兜底，**离线也能跑通完整闭环**。

---

## 一、核心闭环

```
[数据导入] 近3年利润表 + 资产负债表 + 科目余额表（Excel/CSV）
    ↓
[第一轮·AI诊断] 行业对标 → 税负率诊断 + 成本费用结构真实性分析
    ↓ 输出初稿：该有没的 / 可有可没有 / 真实性风险
[多轮互动] 你输入战略意图 → 系统每轮给 3 个选项 → 你选/补充
    ↓
[第二稿] 加入 环比同比、增值比例与幅度、操作细节与注意事项
    ↓ 双方确认 或 落地性 >95%
[完整方案] Word/PDF 报告 + 成本优化测算模型（Excel，可逐月跟踪）
```

## 二、安装与运行

完整的 macOS 安装、启动、环境检查与常见问题，请见[安装使用指南](docs/01_使用与发布/利润宝_macOS安装使用指南_WB-CO-TR-20260726.md)。全部项目资料可从[文档索引](docs/CO_文档索引_WB-CO-TR-20260805153703.md)进入。

> Web 端是本项目**唯一入口**（Tk 桌面端已于 2026-08 移除）。财报导入已接入真实后端计算，支持 **Excel（.xlsx）、CSV、Word（.docx）、PowerPoint（.pptx）、PDF** 五种格式。

### 方式 A：macOS 双击脚本（推荐，适合财税/代账同事）

1. 解压发布包得到 `利润宝-v1.0.0-macOS源码版_WB-CO-TR-20260726/` 目录。
2. 进入 `scripts/` 目录，**双击** `安装利润宝_WB-CO-TR-20260726.command`：
   - 自动寻找 Python 3.13/3.12/3.11（推荐 Homebrew Python 3.13）
   - 在项目根创建 `.venv/` 并安装 `requirements.txt`
   - 失败时给出中文提示，不静默失败、不自动安装 Homebrew
3. **双击** `启动利润宝Web_WB-CO-TR-20260805160732.command`，自动在本机启动服务并打开浏览器 `http://127.0.0.1:8765`。
4. （可选）双击 `环境检查_WB-CO-TR-20260726.command` 检查环境；双击 `质量检查_WB-CO-TR-20260726.command` 运行全量回归。

### 导入与 AI 功能

1. 构建前端：进入 `web_frontend/` 执行 `npm install && npm run build`。
2. 导入方式：
   - **拖拽/选择**：把多年审计报告的文件或文件夹拖到导入区（或点「选择文件夹」「选择多个文件」），一次导入多份并自动按 科目+年份 合并成多年数据集（科目余额表也按年保留）
   - 上传成功后右上角弹出「上传成功」提示
   - **总览 AI 合并**：导入后总览页可点「AI 合并多年报告」，用 AI 从审计报告 OCR 文本生成跨年对比综合报告（营收/成本/净利率逐年对比）
3. PDF 支持：预览按页采集**文本层 + OCR 文字**（RapidOCR，识别中文/数字/科目名），不再渲染 base64 大图——三份几十页的审计报告预览响应从约 60MB 降到约几十 KB，浏览器不卡；预览自动标注 **扫描件**（无文本层），导入前需配置 AI；**AI 整理** 可基于 OCR 文本理解 PDF 内容。
4. **AI 配置（可选，全局一次配置）**：在「设置」页或导入页「配置 AI」填入 Base URL / 模型 / API Key，保存后**全局生效、重启免重输**（持久化到本机 `.ai_config.json`，已 gitignore 不入库）。配置后用于扫描件 PDF 导入解析、AI 整理、跨年合并报告、模板工作台指标识别。
5. **模板工作台 AI 识别**：配置 AI 后打开模板工作台，AI 从审计报告 OCR 原文自动识别营业收入/营业成本（本年+上年）填入顶部输入，比结构化提取更准；未配置 AI 时回退结构化提取（徽标区分「AI 识别」/「结构化提取」）。
6. 也可用「载入示例数据」直接体验：内置示例含研发费用缺失、业务招待费超限、咨询服务费偏高、增值税税负率偏低等典型问题。

### 环境要求

- macOS 12+ / Python 3.11+（推荐 Homebrew Python 3.13）
- 依赖均为纯 Python，无需编译；**离线优先**，AI 引擎未配置时不触网
- **目标分发为 GitHub 私有仓库**，不开源；客户财务数据只在本机处理

## 三、数据模板（Excel）

单个 Excel 含 3 个 Sheet，或分别用多个文件导入：

| Sheet | 结构 | 说明 |
|---|---|---|
| `利润表` | 首列=项目，其余列=各年金额（表头如 `2021`/`2022`/`2023`） | 营业收入、营业成本、税金及附加、销售/管理/研发/财务费用、利润总额、所得税费用、净利润等 |
| `资产负债表` | 同上 | 资产总额、负债总额、所有者权益、应收账款、存货、固定资产等 |
| `科目余额表` | 列含 `科目名称`、`期末余额`（或期末借/贷方） | 用于费用真实性归并：福利费、教育经费、业务招待费、广告宣传费、咨询服务费、研发费用、折旧等 |

不同财务软件（金蝶/用友）导出的项目名差异，已通过**同义词词典**自动归并到规范科目。
可用 `.venv/bin/python data/make_sample.py` 生成一份制造业示例数据（刻意埋了典型问题）直接体验。

## 四、交互说明

- 诊断完成后进入互动区，**每轮针对一条发现给出 A/B/C 三个选项**（每个选项都带影响测算与落地可行性）。
- 你也可在输入框**补充战略意图**（如"我们想往研发型企业转型"），系统会记录并据此继续给选项。
- 所有发现处理完 → 自动生成**第二稿**（含历史环比同比、后续增值比例/幅度、操作细节、注意事项）。
- 回复「确认/落地」→ 输出**完整方案**，落地性评估同步给出（默认选 A 即达 100%）。
- 导出：`导出 Word`、`导出 PDF`（交付客户）、`导出测算模型`（Excel，含当前值→目标值、变动幅度、节税测算、执行清单，可逐月勾选跟踪）。

## 五、诊断维度（节选）

- **税负率**：增值税税负率（基于税金及附加反推，已标注"估算"）、所得税税负率、综合税负率，对标行业区间。
- **成本费用结构**：毛利率、各项费用率、期间费用率、净利率，识别"该有没的"（如研发费用缺失、福利/教育经费未用足限额）与"可有可没有/应控"（如招待费超限、咨询费占比偏高）。
- **真实性**：增值税税负率异常偏低、咨询费占比过高等"四流合一"风险预警。

## 六、合规声明

本工具所有优化建议均锚定**合法税务筹划**范畴（研发费用加计扣除、小微企业/高新优惠、限额内费用据实扣除、业务模式优化等），**严禁**任何形式的虚开发票、隐匿收入或虚构成本。具体执行前建议与主管税务机关或注册税务师确认，并以企业实际经营情况为准。

## 八、已知限制与后续

- 增值税税负率为**估算值**（由税金及附加反推），如能直连开票/申报系统可取真实应纳税额。
- 行业基准为经验区间，可按机构自身客户样本持续校准。
- 后续可扩展：直连金蝶/用友 API 取数、多客户组合管理、历史方案沉淀与复用、大模型自然语言深度润色。
